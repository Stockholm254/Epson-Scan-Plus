# 版本记录

最新的在最前。各版本开头「打开 `Epson-Scan-plus-v0.4.x/…`」指作者本机的发布目录；0.3.1 及以前的名称是 Film Desk。

## 未发布 看片镜在大窗口里的反光、取中性灰

- **修正：大窗口里看片镜的镜片边缘变成一圈绿色、照出灯箱上别的画面**。镜片要在屏幕上占得大，原来就把眼睛放得离目镜越来越近，大窗口里只剩约 0.25 个底座半径，镜片边缘的视线斜到 60–70°；这时镀膜和目镜内壁的反光取到了下面的灯箱（镀膜边缘偏绿）。现在眼睛固定在真实的距离（镜片边缘约 40°），镜片要多大就把看片镜按比例画大，放大倍率不变；镜片只反射上方的房间，低角度的反光落在目镜的黑色内壁上，看片镜内侧朝下的反光是暗的，任何距离都不再照出灯箱。
- **取中性灰**：
  - 片基和中性灰取样时，鼠标在画布上变成滴管（片基是实心滴管），尖端就是取样点；标定中性点也是滴管，标 IT8 色卡是十字准线。
  - 取完后「自动」白平衡保持开着，按这一点白平衡；通用预设下仍按画面拟合各通道反差，取样点照样是灰的。原来取样会把「自动」关掉，看起来像关闭了白平衡。「重算白平衡」放弃取样点。
- **验证**：自检 436 项全部通过（连续 3 次）。新增：眼睛几乎贴着目镜时镜片边缘也不照出灯箱、没有绿色；应用里眼睛始终在真实距离；中性灰取样时是滴管、回到选择时是箭头；通用预设下取中性灰后该点是灰的、「自动」仍开着。

## 0.6.2 液态玻璃外观、细目镜边框、玻璃推子

打开 `Epson-Scan-plus-v0.6.2/Epson Scan plus.app`，或解压 `Epson-Scan-plus-0.6.2-macOS-arm64.zip`。旧版本保留在各自目录，不被覆盖；请先退出旧版，不要同时运行两个版本。连接 AI 助手时，复制的配置指向当前运行的这份 App，换用新版后请重新复制。液态玻璃外观只在 macOS 26 及以后出现，更早的系统保持原来的控制台外观。

- **液态玻璃外观**（macOS 26；更早的系统保持原来的控制台外观）：
  - **两侧面板浮在灯箱上**：画布占满整个工作区，左右面板是浮在上面的液态玻璃（加了一层烟色，亮灯箱上的文字照样清楚），灯箱从面板下面透出；照片排在两块面板和上下玻璃条之间。拖动面板边缘仍可调宽度。
  - **画布上下两行改成浮动的玻璃条**：上方分成「视图、看片镜、横排」和「工具、适合」两组，下方分成「第几张」和「缩放、旋转、镜像、原片 / 反相」两组，各自是浮在画面上的玻璃胶囊。
  - **按键、开关和读数**：金属按键改成透明胶囊（按下变亮，锁定时琥珀色，主操作整颗琥珀色）；指示灯开关在胶囊里亮琥珀色小灯；琥珀色液晶读数改成烟色小胶囊；顶栏去掉金属渐变。玻璃叠玻璃会发灰，所以面板里的按键不是真玻璃，真玻璃只用在面板、浮动条、浮动牌和推钮上。
  - **去漏光页**：分隔线上有玻璃拖柄，在照片上任意位置左右拖都能移动分隔线；右侧面板也浮成玻璃卡片。
  - 灯箱和胶片条上的画面是内容，保持原样。

- **目镜边框改细**：贴近目镜看时只画镜片外一圈细边框（约镜片半径的 12%），再往外直接是灯箱，不再被透视放大的整个橡胶目镜挡住。
- **大视场刚好和照片一样宽**：单张视图中大视场的镜片直径等于照片在屏幕上的宽度（横拍照片受窗口高度限制），缩放画面时跟着变；接触表上仍按画布的三分之一。
- **推子改成液态玻璃**：所有推子（调整面板、去漏光页，以及去漏光页的前后对比，原来是系统滑杆）在 macOS 26 上，推钮是系统液态玻璃的胶囊，透出并折射下面的推槽，按住时放大；推槽从默认点（没有默认点时从最左）到当前值亮起琥珀色。旧系统保持金属推钮。
- **验证**：自检 433 项全部通过（连续 3 次）。新增：目镜只剩细边框、外面是灯箱；单张视图大视场与照片同宽；macOS 26 上能在运行时取得系统液态玻璃；画布上有浮动面板和玻璃条时照片排在它们之间、居中，去掉后恢复占满。

## 0.5.0 AI 助手（MCP）

打开 `Epson-Scan-plus-v0.5.0/Epson Scan plus.app`，或解压 `Epson-Scan-plus-0.5.0-macOS-arm64.zip`。旧版本保留在各自目录，不被覆盖；请先退出旧版，不要同时运行两个版本。连接 AI 助手时，复制的配置指向当前运行的这份 App，搬动 App 后请重新复制。

- **AI 助手（MCP）**：App 可以作为 MCP 服务器，让 Claude Desktop、Claude Code 等助手读取和调整去色罩与颜色。
  - **能读**：选中画面的胶片预设与通道斜率、片基 RGB 及来源（手动 / 片间测量 / 本张估计）、整卷估计、白平衡、色阶、影调、扫描 dpi 与对齐到预览的拟合、负片各通道高于片基的密度和正片各通道的百分位与溢出比例；画面列表、预设列表；正片或负片的 JPEG 预览；任意点的负片线性值、密度和正片值。
  - **能改**：选中画面、调整（冷暖、绿 / 洋红、曝光、对比度、饱和度、黑白点、中间调、自动白平衡和色阶、片基逐通道微调）、在一点取片基或中性灰、改用自动片基、选胶片预设、同步到本卷、重置、撤销。每次改动都是一步编辑，可以 ⌘Z；不能扫描、删除、导出或读写其他文件。
  - **怎样连接**：助手启动 `EpsonScanPlus --mcp`（标准 stdio MCP，协议版本 2025-06-18 / 2025-03-26 / 2024-11-05），它自己回答握手和工具列表，把工具调用经只有本用户能访问的本机 socket（`~/Library/Application Support/epscan/mcp.sock`，权限 0600）交给正在运行的 App。默认关闭，在「胶片」页「AI 助手 · MCP」打开；那里可以复制 Claude Desktop 的配置和 Claude Code 的命令。App 没开或没开启时，工具调用返回说明而不是让会话出错。
- **画布上取片基和取中性灰可以撤销**：原来这两步不进撤销记录；现在和助手的取点共用一步编辑。
- **验证**：自检 374 项全部通过（连续 3 次）。新增项覆盖各工具在 App 上的效果（读取、取点、调整与撤销、拒绝未知参数和越界的点、预览尺寸），以及完整的连接路径：自检以 `--mcp` 启动自身作为子进程，经 stdio 和 socket 完成握手、列出工具、调整进入正在运行的 App、拒绝不存在的工具、关闭后返回说明、socket 权限与清理。

## 0.4.9 扫描对齐到预览、按行合并扫描、横排灯箱、扫描头、看片镜的位置、全卷旋转镜像、工具快捷键与更安全的取点

打开 `Epson-Scan-plus-v0.4.9/Epson Scan plus.app`，或解压 `Epson-Scan-plus-0.4.9-macOS-arm64.zip`。旧版本保留在各自目录，不被覆盖；请先退出旧版，不要同时运行两个版本。程序标识改为 `local.epscan.mac`，第一次启动时自动迁移旧设置。

- **每张正式扫描对齐到预览**：实测发现 V850 每次扫描都自己校准读数——正式扫描的蓝色比 600 dpi 预览高约 11.5%，红色黑电平差 120–290 级；而片基和整卷估计是在预览上测的，所以正式扫描和它们不在同一个标尺上（以往由自动白平衡和本机预设的偏移抵消）。现在每张正式扫描到达时，和预览里同一块逐像素配准：先找到亚像素位置（三个通道一起判断），再在平滑处按通道拟合「扫描 = 增益 × 预览 + 偏移」，记入工程；转换、导出、缩略图、整卷估计都换算到预览的标尺读取，原始文件不改动。
  - **精度**：同一张反复扫描，修正后彼此相差不到 0.15%（拟合 R² 0.9997），每张约 0.2 秒。
  - **拒绝**：拟合不吻合（预览后挪动过胶片、画面太平）时不修正，保持原样；标定扫描仪（IT8）仍读原始扫描。
  - **旧工程**：打开 0.4.8 及以前的工程时，自动为其中的正式扫描补做一次配准并保存；命令行导出在导出前配准，但不写回工程。
  - **请重新标定本机预设**：已有的「· V850」预设是在旧标尺上标定的，蓝色约偏 0.05 D。开着自动白平衡时影响很小。
- **按行合并扫描**（「扫描」页，默认打开，只用于 48-bit 接口）：片夹里并排的几张一次扫完，再按每张的位置切成各自的原始文件（和单独扫描一样保存、记录扫描范围），合并的扫描文件随后删除；切分失败时保留合并文件并停止，说明原因。
  - **只在更快时合并**：按实测的扫描时间模型（每次固定 8.5 秒加按窗口宽度增加的准备时间，之后按「每秒约 102 行」和「每秒约 3.5 MB」中较慢的一个计）决定怎么分组，这个模型对 7 次实测的误差在 7% 以内。满片夹 18 张约 9 分钟（逐张约 13 分钟）；只有一条胶片、一排只勾一张、或隔着一条的两张都照常逐张扫；单次不超过 700 MB。
  - **颜色**：比一张宽的窗口，扫描仪每次校准的蓝色增益不同（−0.4% 到 +3.8%），黑电平也会漂；对齐到预览后与单独扫描相差不到 0.15%。实机按行扫一排（3 张）89.8 秒，切分正常。
  - 进度按一次扫描的几张一起计（「第 7–9 / 18 张 · 本行 42%」），扫描头横跨整排；扫描前确认里显示「18 张分 6 次扫完」。预计用时改用上面的模型，并按本机每次实测校准（存为新的设置项，不沿用 0.4.8 按每百万像素记的速度）。
- **Film Desk 的名字全部改为 epscan**：
  - **存储位置**：默认改为 `~/Pictures/epscan`。旧的 `~/Pictures/Film Desk` 原样保留，不移动也不改动；新库里还没有工程时，「打开工程」先打开旧文件夹。之前自己选过的存储位置照旧使用。
  - **设置**：程序标识改为 `local.epscan.mac`。第一次启动时，从旧标识 `local.filmdesk.mac` 迁移一次全部设置（本机预设、锐化配置、IT8 标定、接触表设置、存储位置等），已在新版里改过的设置不被覆盖，窗口状态不迁移。
  - **工程文件**：新工程保存为 `Session.epscan`；打开的旧 `Session.filmdesk` 照常读取，并存回原文件，不会多出一份。
  - 源代码文件夹改为 `epscan`，测试卷改为 `epscan Test Roll`；构建脚本不再接受旧的 `FILMDESK_*` 环境变量。版本记录里提到 Film Desk 的历史条目保留原样。
- **扫描头**：正式扫描时，正在扫描的那张上出现一个 3D 渲染的扫描头，按扫描进度从画面一端走到另一端（V850 从片床顶端往下读；驱动每读一块数据报告一次进度，扫描头在两次报告之间平滑移动）。
  - **外观**：和看片镜一样用 Metal 逐像素光线步进渲染，处在同一个房间光照里：黑色缎面机身、拉丝铝顶板，灯管从两侧底部透出；灯光照亮下方的一条胶片，往两侧渐暗；左上方柔光箱给它投下影子。
  - **在哪里显示**：接触表上和单张视图中都有，跟着灯箱的横排和镜像。扫描结束或取消后消失。

- **「重置」不再破坏线性扫描**：原来会把输入 Gamma 改回 2.2，48-bit 线性扫描（应为 1.0）重置后转换出错。现在重置只恢复调整，输入 Gamma、正负片、方向和整卷估计保留。

- **宽色域导出**：「输出」页新增「色彩空间」：sRGB、Display P3、Adobe RGB (1998)、ProPhoto RGB，并嵌入对应的 ICC 配置文件。
  - **怎样转换**：程序的转换结果按 sRGB 定义。宽色域导出不在 sRGB 里截断，而是用 ColorSync 转换到目标色彩空间，所以饱和度推到 sRGB 以外的颜色得以保留（测试中一块红色在 sRGB 里绿通道截为 0，在 ProPhoto 里保留为 −0.029）。sRGB 以内的颜色在四种色彩空间里一致。
  - **局限**：去色罩本身仍把各通道映射到 sRGB 的范围；要得到超出 sRGB 的胶片原色，需要按相纸染料建模，是另一项工作。接触表仍为 sRGB。ProPhoto 请配合 16-bit 格式。
  - 命令行导出新增 `--color-space srgb|p3|adobe|prophoto`。
- **导出元数据**：TIFF、JPEG 和 PNG 写入：
  - 标题（胶片 · 片号）、说明（胶片、片号、dpi、是否预览、扫描仪）、关键词（胶片、画幅、胶片扫描）；

  - 拍摄日期程序无从得知，不写；导入的文件不写扫描仪。
  - 实测：扫描仪实测中自动导出的 TIFF 和 JPEG 均带有上述元数据。
- **文件名模板**：「输出」页可设文件名，`{film}` 预设简称、`{name}` 胶片名、`{frame}` 片号、`{roll}` 工程文件夹、`{date}` 扫描日期，默认 `{film}_{frame}`（如 `portra160_09.tif`）。原来固定附加 6 位随机字符；现在同名文件已存在时加序号（`-2`），不会覆盖。
- **胶片的趾部（暗部）**：
  - **数据表曲线**：从 Kodak E-4051、E-4050、E-4046 的矢量特性曲线逐点测得三种胶片的直线段斜率（与原数据表斜率一致）和趾部宽度，拟合误差不超过 0.03 D：Portra 160 为 R 0.16 · G 0.11 · B 0.15（log 曝光），Portra 400 为 0.165 / 0.115 / 0.145，Ektar 100 为 0.13 / 0.10 / 0.075。Ektar 的红、绿在最亮端还有约 0.08 D 的肩部，这一版未建模。
  - **趾部模型**：D = Dmin + 斜率 · w · ln(1 + e^(x / w))，转换时求逆；在片基附近封顶，不放大颗粒。只有测得了片基（片间测量或手动取片基）时才使用，因为从画面自身推测的片基已经在趾部上。
  - **数据表的趾部不直接用于转换**：在 V850 扫描的同一卷 Portra 160（两次独立扫描、三段子集一致）上，按局部明暗过渡测得红、绿梯度比在片基附近从约 0.78 降到 0.68，与数据表大致相符；蓝、绿比却在 0–0.7 D 之间从约 1.0 一直升到 1.35，与数据表（约 1.2–1.3、近乎不变）不符。直接按数据表还原时，暗部打开了，但整张偏粉、发灰。所以默认转换仍是直线，与 0.4.7 相同。
  - **由本机标定测出趾部**：本机预设标定的中性点达到 4 个以上、其中有绿色密度低于 0.25 D 的很暗的点时（例如灰卡欠曝 2–3 档的包围），会同时拟合红、蓝的趾部宽度（绿色沿用数据表），生成的预设按它们还原暗部。合成测试中，5 个中性点准确还原了斜率和趾部（R 0.50 / 0.22、B 0.66 / 0.30）；用这样的趾部转换，灰阶保持中性（偏色 1 级，直线为 26 级），暗部层次从 29 级拉开到 43 级。中性点不够暗时照旧按直线标定。
  - 整卷估计在有趾部的预设下按趾部加权；在有趾部的合成卷上仍准确（R 0.510 · B 0.650）。
- **IT8 扫描仪标定**（「扫描」页）：
  - **流程**：导入与色卡批号一致的 IT8.7/1 参考文件（CGATS 文本，读入 X-Rite 的 MONT45.2022.07 无误：288 个色块与灰阶），把色卡放进 4×5 片夹扫描，在单张视图依次点色块 A01、A22、L01、L22 和灰阶两端的中心；点到第 4 个就标出全部色块的位置以便检查，然后生成标定。
  - **测得什么**：灰阶（Dmin、GS01–GS22、Dmax，最暗约 2.7 D）给出各通道的杂散光：它会抬高底片密实处的读数，使高光发灰。全部色块再拟合一个 3×3 矩阵，报告平均和最大 ΔE。
  - **用在哪里**：本程序的线性扫描和 48-bit 预览在转换前扣除测得的杂散光（可关闭）；导入的文件和旧的 24-bit 扫描不受影响。色块矩阵描述的是色卡反转片的染料，负片转换不使用，只作评估。
  - **验证**：合成色卡上准确测回各通道的杂散光（R 0.400% · G 0.300% · B 0.598%，真值 0.4 / 0.3 / 0.6），灰阶最密一级的误差从 0.48 D 降到 0.001 D，色块矩阵 ΔE 0.00。**尚未用实物色卡扫描验证。**
- **工具更易认**：
  - 工具栏的两个吸管不再一样：取片基是实心吸管并标「片基」，取中性灰是空心吸管并标「中性灰」；本机预设标定的取点换成靶心图标。鼠标停留时说明每个工具做什么。

- **批量扫描前确认**：「扫描所选」和菜单「扫描勾选画面」扫描两张以上时先弹出确认，列出：

  - 其中已扫描过、会再扫一次的张数（旧文件保留）；
  - 预计用时：按 V850 实测（2400 dpi 一张约 45 秒）粗略估计；每扫完一张记下本机在该分辨率下的速度，之后按实测估计；
  - 占用空间：原始负片，加上自动导出的正片（按当前格式），以及存储位置的可用空间。

## 0.4.7 灯箱上的看片镜、600 dpi 预览与更稳的画面识别

打开 `Epson-Scan-plus-v0.4.7/Epson Scan plus.app`，或解压 `Epson-Scan-plus-0.4.7-macOS-arm64.zip`。旧版本保留在各自目录，不被覆盖；请先退出旧版，不要同时运行两个版本。

- **看片镜**：接触表视图的灯箱上放着一只 3D 渲染的看片镜，默认在灯箱右下角。
  - **操作**：拖到画面上放大细看；拿起时稍离开灯箱，影子变淡、画面失焦，放下后重新对焦。双击放回灯箱边；右键可选型号、放回或收起。工具栏「看片镜」键和「画面」菜单（⌥⌘L）显示或收起。

  - **渲染**：Metal 逐像素光线步进，每像素 4 个采样。
    - 透明底座透出并折射下面的胶片和标签，灯箱的光从底边导上来。
    - 黑色机身反射上方的柔光箱和下面发亮的灯箱。
    - 镜片带镀膜反光、轻微畸变和边缘色差。
    - 室内光从左上方来，影子落在右下。视点在灯箱前方，看片镜离画面中心越远，越能看到它的侧面。
  - **镜片里的画面**来自画面本身的像素：正式扫描过的用扫描文件，其余用整幅预览的全分辨率；与接触表一样按「原片 / 反相」显示。修改调整后自动重新生成，新画面出来前保留原来的，镜片不会变空。
  - **性能**：拖动时每一步约 2–4 ms，只重绘看片镜，接触表不重绘。
  - 单张视图里的「放大镜」工具不变。
- **预览分辨率可选，默认 600 dpi**：「扫描」页新增「预览」选项。
  - **实测整个片夹**（149 × 246 mm）：150 dpi 50 秒，300 dpi 76 秒，600 dpi 79 秒（3520 × 5816）。300 dpi 几乎不比 600 dpi 快，所以只提供 600 和 150。
  - **效果**：600 dpi 时每张 35 mm 约 850 像素（150 dpi 约 210），未正式扫描的画面在单张视图、导出和看片镜里都清楚得多。

  - **内存**：识别画面、接触表和片基统计用 2200 像素的工作副本；单张画面从全分辨率裁切，全分辨率只读取一次。
  - **识别画面**：先平均到 150 dpi 的尺度再识别。直接在 600 dpi 上识别时，同一片夹两次扫描的画框边缘可相差 9 mm；平均后，三次 300 / 600 dpi 预览之间一致（框高 35.2–36.9 mm）。150 dpi 预览不受影响。
  - **整卷估计**：600 dpi 预览上为 R 0.422 · B 0.611（150 dpi 时 R 0.425 · B 0.624；手动标定 R 0.417 · B 0.586）。
- **实机验证**（2026-10-27，同一卷，开发版）：
  - 以 600 dpi 预览跑完整实测，通过：识别 18 张，第 9 张 2400 dpi 扫描和自动导出正常，全程 132 秒（150 dpi 预览时 102–107 秒）。
  - 改进画面识别后再跑一次，通过：18 张框高 35.2–36.2 mm，第 9 张扫描区高 35.7 mm（改进前那次为 37.8 mm），全程 131 秒，整卷估计 R 0.420 · B 0.612。
- **135 画面识别更稳**：
  - **问题**：这卷的一次 150 dpi 预览中，第 1、4、6、18 张的框高被识别为 37–44 mm（应约 36 mm）。原因是片夹透光窗口比胶片长出 6–10 mm，旧方法按窗口长度平均分割，所有切口一起偏移，端头一张还吞下了多出的部分。
  - **做法**：135 的画面按固定间距（约 38 mm）前进，现在一次拟合整条的所有切口，再让每个切口在约 1 mm 内对准自己的片间间隙；两端的画面最多一个间距长，并且不长于同条其他画面；同一条上某张的侧边如果偏离全条超过 0.6 mm（暗景被当成片基裁掉），改用全条的侧边。120 不变。
  - **结果**：同一片夹的六次预览（150 / 300 / 600 dpi）全部识别为 18 张，每张高 35.2–36.2 mm，各张边缘在六次之间相差不超过 1 mm（原来最多 9.6 mm）。
  - **新测试**：合成的 135 胶片条，透光窗口在末端多照到 10 mm 雾化片基、第 4 张是一片暗色。旧方法得到 42.0 和 43.2 mm 的画框，新方法六张一致。
- **实测模式不再要求 18 张**：`--sane-hardware-test` 适用于片夹里的任何胶片，识别到的张数只记录在报告中。
- **界面细节**：「扫描」页的存储位置以 `~` 缩写显示；单张视图底部对 600 dpi 预览显示「600 dpi 预览」，不再写「低清预览」。
- **验证**：自检 221 项全部通过（连续 3 次）；附加 `--overview` 时，改进前识别出错的那次 150 dpi 预览和 600 dpi 预览都识别为 18 张。新增项覆盖：
  - 看片镜的放大倍率、画面来源、材质、影子和透视；
  - 拖动、双击放回、窗口改变大小时留在角落、修改调整后保留旧画面并自动更新、移动画框后立即丢弃旧画面、收起，以及单张视图中不显示；
  - 预览分辨率的设置与保存、600 dpi 预览的存储与逐张裁切；
  - 透光窗口超出胶片、含暗色平淡画面的 135 胶片条。

## 0.4.6 Metal 着色的灯箱与更准的整卷估计

打开 `Epson-Scan-plus-v0.4.6/Epson Scan plus.app`，或解压 `Epson-Scan-plus-0.4.6-macOS-arm64.zip`。旧版本保留在各自目录，不被覆盖；请先退出旧版，不要同时运行两个版本。

- **整卷自动估计改用局部明暗过渡**（没有本机预设时的通道斜率）：
  - **原理**：明暗变化（阴影过渡、纹理、褶皱、波浪）在各通道的 log 曝光上变化相同，所以在绿色密度变化的地方，红、蓝按各自斜率之比变化。这与色彩恒常研究中的 gray-edge 假设同理。程序取整卷所有明暗过渡处的比值的中位数。
  - **旧方法的问题**：旧方法比较整卷的整体明暗分布，会把「亮处是蓝天、暗处是暖色地面」误当成蓝通道反差大。
  - **在一卷 18 张的海边胶卷上验证**（对照手动 3 点标定：R 0.417 · B 0.586，颜色交叉在该卷 4.2 档的曝光范围内计算）：

    | 方法 | 斜率 R / B | 颜色交叉 R / B |
    |---|---|---|
    | Kodak 数据表 | 0.520 / 0.620 | 0.43 / 0.12 档 |
    | 0.4.5 整体分布 | 0.395 / 0.696 | 0.12 / 0.34 档 |
    | 0.4.6 明暗过渡 | 0.419 / 0.614 | 0.01 / 0.10 档 |

  - **稳定性**：前、中、后三段各 6 张分别估计，R 0.413–0.433，B 0.558–0.645。随机抽 2 张时，偏差中位数约 0.17 档；6 张约 0.11 档。仍需至少 2 张，不足时用数据表。
  - **对照显示**：有本机预设时仍用预设；「胶片」页同时显示本卷的估计作对照，两者相差很大时，说明这卷可能与标定时的胶片或冲洗不同。

  - **新测试**：合成的海边画面（亮处偏蓝、暗处偏暖），旧方法得 B 0.773（真值 0.65），新方法准确还原。
- **接触表视图的灯箱改为逐像素着色**：用 Metal 计算，着色程序在 App 第一次需要时现场编译，所以构建仍然不需要 Xcode。
  - **玻璃**：中性乳白，原来偏暖，会影响判色；中心略亮、向边缘衰减，带细微颗粒，靠近边框处被框沿压暗。去掉了原来的网格线。

  - **性能**：按窗口尺寸和屏幕分辨率渲染一次并缓存，鼠标移动时只贴图。

## 0.4.4 设置、接触表、锐化与胶片预设标定

打开 `Epson-Scan-plus-v0.4.4/Epson Scan plus.app`，或解压 `Epson-Scan-plus-0.4.4-macOS-arm64.zip`。旧版本保留在各自目录，不被覆盖；请先退出旧版，不要同时运行两个版本。

本版改动了色彩处理：胶片预设、曝光、浮点统计和整卷片基都会改变，已有工程打开后颜色可能与 0.4.3 不同，原始扫描文件不受影响。以下功能尚未在扫描仪上实机复测：以 1200 dpi 扫描后生成接触表、对真实 48-bit 扫描的锐化，以及用真实灰卡标定预设。

- **胶片预设现在真正生效**：此前开启自动白平衡（默认）时，各通道按画面反差重新拉伸，抵消了预设的通道斜率。Portra 160、Portra 400、Ektar 100 的结果与「通用」逐像素相同。现在选择具体胶片时，通道反差按预设斜率决定，自动白平衡只对齐各通道黑点；「通用」仍按画面拉伸，可以自动修正颜色交叉。
  - **影响**：使用具体胶片预设的已有工程（默认是 Portra 160）颜色会变化。
  - **建议**：若负片与预设差异较大，暗部或亮部出现偏色时，改用「通用」，或用「选取中性灰」。
- **曝光改为印放曝光**：曝光原先是在裁切和中间调之后把显示值乘以 2^EV，+EV 会直接冲掉高光，−EV 也找不回已裁掉的高光。现在按每档 0.301 平移密度，在色阶与裁切之前生效。曝光为 0 的工程结果不变。
- **调整面板重新分组**：「色阶」只放自动、黑点、白点、中间调；曝光和对比度移到「影调」，饱和度移到「色彩」。
- **接触表视图可切换原片 / 反相**，默认反相：每张按各自的调色显示为正片，片边与片夹按本卷片基反相，看起来像一张接触印样。
- **设置（`⌘,`）**：
  - **扫描存储位置**：新的预览和导入会在此新建工程文件夹，已有工程不移动。
  - **默认导出格式**：TIFF 16-bit / TIFF 8-bit / JPEG / PNG 16-bit，可调 JPEG 质量。导出对话框中也能临时更换格式，命令行 `--format` 同样支持这四种。
  - **接触表排列**：胶片条或网格、每条 / 每行张数、白色相纸或黑底、是否按每张旋转、片号与标题。
- **导出接触表（`⌥⌘E`）**：把勾选画面排成一张 1200 dpi 的图片。
  - 尚未扫描或低于 1200 dpi 的画面先以 1200 dpi 扫描，结果保存为这些画面的原始文件；已有更高分辨率的扫描直接使用。
  - 先选好保存位置再开始扫描；取消或扫描失败时不生成接触表。
  - 扫描仪未就绪时，可选择用低清预览生成。
- **去色罩精度**（按调研的第一优先级）：
  - **浮点统计**：自动色彩统计和片基、中性点取样改用浮点数据。此前在 8-bit 数据上计算，线性扫描中负片的高密区只剩个位数的码值，片基、黑白端点和中性点都会被量化。
  - **按密度排除**：原先固定排除各通道都低于 0.025 的像素，在线性扫描里会把负片最密的高光整片丢掉，导致高光被裁切。现在只排除在每个通道上都比片基密 3.0 D 以上的近乎不透光区域，例如片夹和画框线。
  - **整卷片基**：从总览扫描中相邻画面之间的未曝光片基读取，供整卷共享，不再用每张画面里最薄的景物估计，因此高调画面也不会把片基估得偏密。手动「取片基」仍然优先。
  - **何时使用整卷片基**：只用于本程序的 48-bit 预览，以及画面裁自同一导入胶片条的情况；片间不干净或找不到间隙时，回退到逐张估计。调整面板会注明当前片基来自哪里。
  - **影响**：线性 48-bit 扫描的已有工程，颜色和高光会有变化。
- **本机胶片预设标定**（按 RawTherapee 的中性点反解）：
  - **原理**：中性物体在三个通道上的 log 曝光相同，所以每个通道的密度都可以写成「斜率 × 曝光 + 偏移」。以绿色为基准，绿色斜率沿用起始预设，由明暗不同的中性点反解红、蓝通道的斜率与中性偏移。2 个点时精确求解；3 个点以上用最小二乘拟合，并检查一致性。
  - **用法**：先在「预设」中选好胶片。在左侧「胶片 → 本机预设标定」点「取中性点」，在单张中依次点选中性灰；可以跨画面、跨卷。然后点「生成 V850 预设」。新预设名为「胶片名 · V850」，自动应用到当前工程，并保存在本机设置中；可在「设置 → 胶片预设」导出 JSON 或删除。
  - **斜率**：决定各通道反差，开启自动白平衡时同样生效。
  - **中性偏移**：在关闭自动白平衡、且没有手动中性点时，按标定结果配平。
  - **会拒绝的情况**：少于 2 个点；绿色密度跨度不足 0.3 D；解出的斜率超出 0.1–2.0；3 个点以上时拟合残差超过 0.08 D，通常说明有的点不是中性灰。
  - **验证**：合成数据上，2 个或 3 个点都能精确还原斜率与偏移；±0.01 D 噪声下斜率误差约 1.5%；混入一个偏色点会被拒绝。同一条中性灰阶在关闭自动白平衡时，标定预设的偏色为 0.0 级，数据表预设为 30 级。
  - **需要怎样的画面**：
    - **最好**：拍一张灰卡（18% 中灰，或白卡、灰卡、黑卡的组合），在同一卷上用 −2、0、+2 档包围曝光，日光下拍摄，与胶片的色温匹配。
    - **其次**：带灰阶的色卡（例如 ColorChecker 底排的六个灰块），或画面里确定是中性的大面积物体，例如白墙、灰色水泥、阴天天空下的灰色路面。
    - **取点**：落在均匀处，避开高光溢出、几乎透明的阴影趾部和反光。各点至少相差 1 档，绿色密度 0.3 D；最好覆盖 2 档以上。
    - **条件**：与要转换的胶片同一型号、同一冲洗方式，用这台 V850、同一片夹扫描。不同胶片型号要分别标定；同一型号的不同卷片基各不相同，由整卷片基分别处理，预设可以通用。
- **按实测 MTF 锐化**：
  - **建立配置**：在「设置 → 锐化」导入一张分辨率标靶的扫描（需带实心方块，例如 USAF 1951 或 Vlad 标靶）。程序自动找出可用的方块边缘，用斜边法测量扫描仪横向、竖向的 MTF，按 lp/mm 保存为扫描仪锐化配置，一次测量适用于所有 dpi。
  - **标靶文件**：本程序的 48-bit 扫描视为线性数据，其他软件的文件按 Gamma 2.2 线性化。
  - **锐化方式**：在负片转换之前，于线性扫描数据上做反卷积（Wiener），提高细节反差，同时抑制光学极限以上的噪声。
  - **默认值**：正式扫描的画面默认温和强度（40%），导入的图像默认关闭；调整面板「锐化」可逐张调整，推到 0 关闭。
  - **作用范围**：单张视图、放大镜、导出和接触表都会使用。
  - **本机实测**（V850，6400 dpi，Vlad 标靶）：横向约 2240 ppi，竖向约 1720 ppi，由 8 条竖直边缘、7 条水平边缘测得。默认强度下，横向 MTF50 从 17.5 提高到 31.6 lp/mm，竖向从 14.4 提高到 25.4，噪声增加约 19%。整张 6400 dpi 图像锐化约 1.5 秒。
  - **限制**：配置只适用于测量时的片夹与对焦高度。锐化不能超出光学极限，35mm 用 3200 dpi 扫描已能拿到这台扫描仪几乎全部的细节。
- **验证**：自检 153 项全部通过，新增项覆盖：
  - 线性负片的高密高光保留层次。
  - 片间片基读取误差在 1% 以内，画面无间隙或间隙为片夹时不会误用。
  - 片基优先级正确，重置调整时保留整卷片基。
  - 已知模糊的合成标靶测得 MTF50 11.86 lp/mm，理论值 11.80。
  - 反卷积提高边缘 MTF50，平坦区亮度不变。
  - 正式扫描默认锐化，导入与预览默认不锐化。
  - 锐化配置在重启后保留。
- **此前新增项覆盖**：
  - 预设生效，且匹配预设时中性灰保持中性。
  - −EV 能找回被裁掉的高光。
  - 四种导出格式的类型与位深都正确。
  - 设置在重启后保留。
  - 两种接触表排列都能导出，尺寸正确。
  - 反相视图中，片基为黑、片夹为白。

  **尚未验证**：没有在扫描仪上实测「以 1200 dpi 扫描后生成接触表」。

## 0.4.0 真正的 RGB 48-bit 采集（实验）

打开 `Epson-Scan-plus-v0.4.0/Epson Scan plus.app`，或解压 `Epson-Scan-plus-0.4.0-macOS-arm64.zip`。适用于 Apple Silicon Mac、macOS 14 及以上，实验接口只启用 USB `04b8:0151` 的 V800/V850。本机实测识别为 GT-X980。

1. 退出 Epson Scan 2、图像捕捉及其他扫描程序，打开新版。检测成功后左侧显示「48-bit RGB」与「epson2 · 48-bit 实验接口」。
2. **先重新预览**。新接口的采集坐标与输入编码独立记录，不能直接沿用 ICA 工程的预览进行扫描。新预览会建立新工程，旧工程与原图不覆盖。
3. 选择 dpi，先用扫描菜单的「扫描当前画面」试一张，再批量扫描。仍保留单张自动进入、左右键浏览、勾选/全选/全不选、裁切与片基微调、批次进度。
4. 原始 TIFF 为不反相的 RGB16/通道，关闭扫描仪 CCT 色彩校正，设置三通道恒等 Gamma 表；本程序新工程使用输入 Gamma 1.0。原件偏暗是线性编码的正常表现，不是已转正成片。
5. 转正导出可选 TIFF 16-bit/通道或 JPEG。将这里的原始 TIFF 再作为普通图片单独导入时，也请确认「输入设置」Gamma 为 1.0；普通导入不会猜测文件是否线性。

预览也采集 48-bit，显示缩略图仍是屏幕预览。正式扫描的像素按驱动实际对齐范围记录，避免用名义玻璃尺寸拉伸预览坐标；对齐的少量外围像素只在原件保留，导出按用户裁切。进度由读取到的图像字节推动，TIFF 保存并成功返回才计为完成，不是剩余时间估算。

**实验接口的取消不是立刻让机械运动停止。** 本机中途发送停止命令后曾出现 USB 不响应，因此改为读取完当前传输、等待本张扫描结束后停止，不保存该张，也不启动下一张。界面会保持「正在取消」，完成后才解锁。扫描中退出程序也会通知独立采集进程执行这一步，归位前不要打开另一扫描程序。若扫描仪已经报错或断线，可能仍需要关机再开机。

目前属于**本机验证的实验接口**，不等同于 Epson 官方「High」品质模式；没有 ICE、红外或软件除尘，也没有 IT8 标定。高于 8-bit 的实际像素取值验证可以排除简单扩位，但不能证明传感器拥有 16 位有效动态范围。原始文件的线性 RGB 编码标记不是扫描仪专用 ICC。2400 dpi 的一张 RGB48 原件通常约为同尺寸 RGB24 的两倍数据量。

0.3.3 稳定版仍在独立目录。开发诊断时可使用本版可执行文件的 `--ica` 参数启动旧 ICA 接口；不会静默降级或把 24-bit 采集标成 48-bit。请勿同时运行两种接口。

本版包含的 SANE、libusb 许可证、对应源代码与 helper 源码位于应用包 `Contents/Resources/Scanner` 内；源码包另含可复现构建脚本。详见 `ThirdParty/README.md`。

- 修复放大后的图像越过中央预览区、覆盖工具栏和底部胶片条的问题。画布、图层和绘图路径均限制边界，缩放和平移也限制在图像范围内。
- 自动白平衡改为按 RGB 通道的稳健亮暗端点校正，改善只对齐中间调造成的阴影/高光偏色。已有手动设置仍保留；点击右侧「重算白平衡」才会清除旧中性点偏移并启用新算法。
- 单张视图可直接「取片基」，并用「片基微调 · EV」的 RGB 滑块微调，不再跳回接触表。取样后关闭自动白平衡以保留片基效果；RGB 微调不会被自动白平衡抵消。
- 单张右侧「画面范围 → 微调」可拖动四角、移动框或用四边步进器调整。方向键移动 1 个当前预览像素，Shift 加速，回车/「完成」结束。「还原范围」恢复首次编辑前范围。
- 正式扫描后裁切只改参数，不重写或丢弃原始 TIFF，16-bit 导入数据仍保持位深。原扫描没有包含的区域不能凭空恢复；要扩大采集范围，请回接触表调整并重新扫描。

如果从 0.1 升级的某张照片保留旧版手动中性点，可比较「重算白平衡」的结果；夕阳、蓝天等非中性场景仍可能被自动统计调冷，需选真正的中性灰，或用冷暖/片基微调保留现场光色。这不是经过 IT8 标定的颜色保证。150 dpi 预览不是成片，正式扫描后再判断细节。
